# 🚗 Buscador de Carros Multi-Sites

Sistema web para buscar anúncios de carros em múltiplos sites simultaneamente.

## 🌟 Funcionalidades
- 🔍 Busca em WebMotors, Mercado Livre e OLX
- 📊 Dashboard com estatísticas
- 💾 Exportação para Excel e CSV
- 🌐 Interface web responsiva

## 🚀 Tecnologias
- Python 3.11
- Flask
- BeautifulSoup4
- Pandas
- Streamlit

## 📦 Instalação
pip install -r requirements.txt
python app.py

## 🌐 Acessar
http://localhost:5000
